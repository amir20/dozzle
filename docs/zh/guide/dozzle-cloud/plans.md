# 套餐与限制

套餐、价格和额度都列在 [Dozzle Cloud 价格页面](https://cloud.dozzle.dev/pricing)上，那里始终是最新的。本页讲的是当你碰到这些限制时，从你这边看会是什么样子。

## 告警突然变得原始又重复

很可能是你超出了每月的事件额度。什么都不会坏：事件历史仍在记录，但分诊会暂停，大约每十个事件里有一个以原始告警的形式送达，重复也不再被折叠成一条带计数的告警。先去 Cloud 的用量页面看看。额度在每月初重置，付费套餐同样适用。

## 搜上周的东西什么都搜不到

搜索只能回溯到你套餐的保留期为止。更早的内容已经被删除了，尽管它确实发生过。请求比套餐允许更长的指标时间窗时，返回的是你实际拥有的窗口，而不是报错。

## 实例数量限制

免费套餐同时只能连一个实例。连第二个时会显示限制提示。你有两个选择：

- **把名额挪过去。** 在 Instances 页面删除现有实例的 API 密钥，然后连接新的。这对旧实例是不可逆的：它的历史还在，但你得从头重新连接一次。
- **升级套餐**，让两个同时连着。

## 查看用量

Cloud 的用量页面显示本月已用的事件数、日志字节数和助手对话数，以及对应的额度。你也可以在聊天里问：“我这个月用了多少？”

## 更换或取消套餐

在价格页面或设置里升级。计费由 Stripe 处理；支付方式、发票和收据都在那边通过设置里的账单链接管理。

取消会停止后续扣费，并在你已付费的周期结束时把你切回免费套餐。账号和历史都会保留。
