# 套餐与限制

每个套餐包含什么、什么会计入额度，以及超额之后会发生什么。

免费套餐是完整的告警产品，而不是它的试用版。付费套餐买到的是主动的那一半 —— 那个读你日志、找出从来没有触发过告警的问题的巡检 —— 外加更大的运行空间。

## 什么算一次处理事件

**处理事件**指的是走过分诊流水线的一个容器事件或一条匹配的日志行，流水线会决定是发一条新告警、并入已有告警，还是保持沉默。你付费买的是这份工作，不是原始存储。

普通日志行不算事件，它们计入可检索日志量。所以话很多的容器消耗的是存储，崩溃循环的容器消耗的是事件。

如果一个容器退出了 47 次，那是 47 个事件计入额度，但只有一条写着 47 的告警。这正是重点所在。

**发现两样都不消耗。** 日志巡检读的是你的日志而不是告警历史，因此完全不占用事件计数，而且在一条告警规则都没配的情况下也能工作。只有每月日志量会算进去。

**搜索和指标在所有套餐都免费。** 实例一连上搜索索引就开始工作，CPU、内存、网络和磁盘序列从你的实例流过来也不额外收费。套餐只影响数量和能回溯多久。

## 超出额度之后

什么都不会坏。你会进入抽样模式：

- 分诊暂停。
- 事件历史仍在记录，所以什么都不会丢。
- 大约每十个事件里有一个会以**原始**告警的形式送达，你还能看到发生了什么。
- 重复不再被折叠成一条带计数的告警。

实际效果是告警变得更吵、更没用，而不是消失；你会先在收件箱里感觉到，然后才在用量页面上看到。如果你的告警突然变得原始又重复，先去看用量。

付费套餐同样适用。额度在每月初重置。

> [!TIP]
> 大多数账号根本不会接近上限。只有真正的洪流 —— 一个连着好几天崩溃循环的容器 —— 才会超出免费额度，而点名那个容器的告警远在触及上限之前就到了。

## 保留期

保留期决定你的历史能回溯多久：告警、事件和日志搜索结果。免费版是一天，所以搜上周的东西什么都搜不到，尽管它确实发生过。这是搜索看起来“丢数据”的最常见原因。

指标保留期在免费版是 24 小时，付费套餐是 30 天。请求比套餐允许更长的时间窗时，返回的是你实际拥有的窗口，而不是报错。

## 实例数量限制

免费套餐同时只能连一个实例。连第二个时会显示限制提示。你有两个选择：

- **把名额挪过去。** 在 Instances 页面删除现有实例的 API 密钥，然后连接新的。这对旧实例是不可逆的：它的历史还在，但你得从头重新连接一次。
- **升级套餐**，让两个同时连着。

这个限制针对的是免费账号转发多少数据，而不是锁住某个功能。免费版的其他一切，在你已连接的那个实例上都能用。

## 查看用量

Cloud 的用量页面显示本月已用的事件数、日志字节数和助手对话数，以及对应的额度。你也可以在聊天里问：“我这个月用了多少？”

## 更换或取消套餐

在价格页面或设置里升级。计费由 Stripe 处理；支付方式、发票和收据都在那边通过设置里的账单链接管理。

取消会停止后续扣费，并在你已付费的周期结束时把你切回免费套餐。账号和历史都会保留。
