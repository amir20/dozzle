# 支持

Dozzle 是一个开源项目，由作者和贡献者共同维护。如果你有任何疑问、问题或功能需求，欢迎随时联系我们。

支持我们的方式有很多：

- 我们一直在寻找贡献者。如果你有兴趣参与项目，请看看 [Issues](https://github.com/amir20/dozzle/issues)。
- 如果你喜欢这个项目，欢迎到 [GitHub](https://github.com/amir20/dozzle) 上点个 star。
- 如果你想在资金上支持项目，可以来 [Buy Me a Coffee](https://www.buymeacoffee.com/amirraminfar)。
- 写博客介绍它、发推提到它，或者分享到社交媒体上。

感谢你的支持！🙏
