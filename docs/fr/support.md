# Support

Dozzle est un projet open source maintenu par son créateur et ses contributeurs. Si vous avez des questions, des problèmes ou des demandes de fonctionnalités, n'hésitez pas à nous contacter.

Il y a plusieurs façons de nous soutenir :

- Nous cherchons toujours des contributeurs. Si vous souhaitez contribuer au projet, jetez un œil aux [issues](https://github.com/amir20/dozzle/issues).
- Si vous aimez le projet, pensez à lui mettre une étoile sur [GitHub](https://github.com/amir20/dozzle).
- Si vous voulez soutenir le projet financièrement, vous pouvez nous [offrir un café](https://www.buymeacoffee.com/amirraminfar).
- Écrivez un article de blog sur le projet, parlez-en sur les réseaux sociaux ou partagez-le.

Merci pour votre soutien ! 🙏
